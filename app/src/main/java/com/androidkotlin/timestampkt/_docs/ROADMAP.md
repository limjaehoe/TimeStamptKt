# TimeStamptKt 로드맵

## 목적

예전에 1차로 완성해 둔 출근 기록 기능을 바탕으로, 남은 기능을 작은 단위로 나누어 다시 개발하기 위한 문서입니다.

## 현재 앱에서 가능한 것

- 현재 시간 확인
- 출근/업무 기록 추가
- 기록 목록 확인
- 기록 메모 수정
- 기록 삭제
- 전체 기록 삭제
- JSON 백업 파일 저장
- JSON 백업 파일 불러오기
- 연차/휴가 기록 관리
- 연도별 지급/사용/잔여 연차 계산
- 엑셀 형식 연차 기록 붙여넣기 가져오기
- 캘린더에서 출근/연차 기록 표시
- 앱 시작 시 하루 1회 자동 기록
- 설정 화면 이동

## 우선 정리 작업

### 완료

- `presentation/setting` 디렉터리를 `presentation/settings`로 변경
- Gradle `namespace`를 `com.androidkotlin.timestampkt`로 변경
- 기존 설치 앱의 데이터 유지를 위해 `applicationId`는 `com.androidkotlin.timestampkt.data` 유지

### 확인 필요

- PowerShell 기본 출력에서는 한글이 깨져 보일 수 있으므로 `-Encoding utf8`로 확인
- 앱 화면 문구는 기능 구현 과정에서 필요하면 더 자연스럽게 다듬기

## 기능 로드맵

### Phase 1. 기본 안정화

- 기존 기능 빌드 확인

필요 작업:

### Phase 3. 연차/휴가 관리

목표:

- 연차/휴가 사용 기록 추가

- 날짜별 휴가 메모 관리

필요 작업:

- `LeaveRecord` 도메인 모델 추가: 완료

### Phase 4. 통계

- 기간 선택 후 내보내기

- 기간 선택 후 내보내기 추가

## 추천 작업 순서

1. 기존 기능 빌드 확인
2. 기록 추가/수정/삭제 흐름 수동 테스트
3. 연차 추가/수정/삭제 수동 테스트
4. 엑셀 붙여넣기 가져오기 수동 테스트
5. 통계와 내보내기 구현

## 결정이 필요한 것

- 이 앱의 기록이 "출근 시간" 중심인지, "업무 타임스탬프 전체" 중심인지
- 하루에 기록을 여러 개 남기는 흐름을 계속 유지할지
- 자동 기록 문구와 조건을 어떻게 할지
- 연차 계산 기준을 직접 입력할지, 단순 메모형으로 시작할지
- CSV/Excel 내보내기가 필요한지
